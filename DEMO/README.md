# DEMO - запуск лабораторных работ №1-7

На Windows запустите `RUN_DEMO.cmd` из корня репозитория (или `DEMO/RUN.cmd`). При первом запуске создаётся `.venv` и устанавливаются зависимости; нужен Python 3.11+.

| Пункт | Действие |
|---|---|
| 1 | Проверка окружения |
| 2-4 | Запуск ЛР1, ЛР2, ЛР3 |
| 5-9 | Общий прогон, модели, тесты, MLflow и результаты ЛР1-3 |
| 10-13 | ЛР4 - валидатор, негативные проверки, MLflow, отчёт |
| 14-15 | ЛР5 - синтетические данные и отчёт |
| 16-19 | ЛР6 - FastAPI, мониторинг и отчёт |
| 20-21 | ЛР7 - joblib, Evidently и отчёт |
| **22** | [Сводный обзор ЛР1-7](../reports/LABS_OVERVIEW.md) |
| 0 | Выход |

Опубликованные результаты находятся в `reports/LAB1`-`reports/LAB8`. Повторные запуски через DEMO сохраняют вычисленные данные и логи в `demo_output/`; авторские файлы `labN_report.md` не изменяются. ЛР8 пока не включена в меню сдачи.

Отчёты: [`reports/`](../reports/). Для ЛР6 на портах 8000 и 8001 используются два независимых FastAPI-сервиса; интерфейс Swagger доступен по `/docs`.
