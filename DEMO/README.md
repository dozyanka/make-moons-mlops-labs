# DEMO — запуск лабораторных работ на другом компьютере

Эта папка является единой точкой запуска и воспроизведения выполненных лабораторных работ проекта.

## Самый простой запуск

На Windows запустите двойным щелчком:

```text
DEMO\RUN.cmd
```

Также в корне репозитория есть:

```text
RUN_DEMO.cmd
```

Оба варианта открывают одно и то же меню.

## Что делает launcher

При первом запуске launcher:

1. ищет Python 3.11+;
2. если Python не найден и доступен `winget`, пытается установить Python 3.13;
3. создаёт локальное `.venv`;
4. устанавливает зависимости из `pyproject.toml`;
5. проверяет NumPy, pandas, scikit-learn, PyTorch, MLflow, pytest и остальные необходимые библиотеки;
6. открывает меню запуска лабораторных.

Старое виртуальное окружение переносить с другого компьютера не требуется.

## Меню

Из меню можно:

- отдельно выполнить ЛР1;
- отдельно выполнить ЛР2;
- отдельно выполнить ЛР3;
- выполнить ЛР1–ЛР3 последовательно;
- быстро загрузить уже сохранённые модели через `defense_demo`;
- прогнать тесты;
- запустить MLflow UI;
- открыть результаты.

## Оригинальные и воспроизведённые результаты

Официальные результаты, полученные автором и отправленные на проверку:

```text
reports\LAB1
reports\LAB2
reports\LAB3
```

Launcher их не перезаписывает.

Новый запуск на компьютере проверяющего сохраняется отдельно:

```text
demo_output\LAB1
demo_output\LAB2
demo_output\LAB3
demo_output\logs
```

Папка `demo_output` не хранится в Git.

## Быстрая демонстрация и полный прогон

Быстрая демонстрация сохранённых моделей:

```text
DEMO\RUN.cmd
→ пункт 6
```

Полное воспроизведение ЛР1–ЛР3:

```text
DEMO\RUN.cmd
→ пункт 5
```

## GPU

GPU не требуется для запуска ЛР1–ЛР3.

ЛР3 может выполняться на CPU. Ранее выполненная проверка совпадения CPU/GPU сохранена в:

```text
reports\LAB3\device_parity.csv
```

Если на компьютере доступен CUDA-ускоритель, его наличие будет показано при проверке окружения.

## MLflow

После выполнения ЛР2 или ЛР3 MLflow UI можно открыть через пункт 8 меню.

Адрес:

```text
http://127.0.0.1:5000
```

Локальная база `mlflow.db` является runtime-файлом и не хранится в Git.

## Примечание по ЛР1

Официальные логи негативных pre-commit проверок уже сохранены в `reports\LAB1`.

Launcher не создаёт вредные тестовые коммиты в репозитории проверяющего. При обычном воспроизведении выполняются безопасные проверки кода и тесты.
