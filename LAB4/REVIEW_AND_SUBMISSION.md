# ЛР4: рецензия БЯМ, критический комментарий и сдача

После успешной проверки патча №03 и публикации в GitHub, перед сдачей:

1. Подготовить скринкаст на 3–5 минут по `LAB4/SCREENCAST.md`.
2. Передать рецензенту (БЯМ) карточку варианта 09, актуальные отчёты,
   негативные контроли, таблицу повторных прогонов, coverage и точный промпт
   из **Приложения А** письменного задания `labs_new.docx`. При рецензии всех
   восьми работ передать полный пакет работ 1–8; здесь подготовлена лишь ЛР4.
3. Сохранить реальный текст рецензии, не подменяя критические замечания
   поддельной «идеальной» рецензией. Запросить конкретные ссылки на файлы,
   числа и Run ID и пометки «проверить невозможно» для отсутствующих данных.
4. Написать **собственный** критический комментарий не более одной страницы:
   таблица `Пункт рецензии | Согласен / не согласен | Обоснование с доказательством`.
   Особо обсудить необнаруженные flip-метки и ограничения трассировки MLflow.
5. Прикрепить в ЭЮ архив репозитория, GitHub-ссылку, отчёт, скринкаст,
   рецензию БЯМ и критический комментарий. Проверить комплектность
   материалов по `defense_checklist.md`.
