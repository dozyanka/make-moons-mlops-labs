## Честные ограничения локальной проверки

- В этом контейнере MLflow отсутствует: диагностические ID `OFFLINE_NOT_MLFLOW` не заменяют доказательство интеграции. Пользователь ранее подтвердил настоящие два MLflow запуска патча 02; **после патча 03 нужны четыре свежих Run ID и проверка `Finished`**.
- Версия `scikit-learn` в локальной среде отличается от версии, которой сериализован рабочий ML-классификатор; численные проверки выполнены, но предупреждения о совместимости отражены в pytest-логе. Преподавателю лучше установить версии в совместимом окружении.
- Чистота GitHub Actions и исполнение Windows PowerShell на реальном компьютере ещё не проверены.
- Нормативы recall ≥ 0.90 и FPR ≤ 0.05 заданы до теста; идеальная детекция любых чужеродных входов невозможна. Принимаемые OOD явно записываются, без замалчивания.
- Более сложная и обновлённая ЛР8 здесь не реализовывалась: только ЛР4.
