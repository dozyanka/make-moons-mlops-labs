# Патч №06: byte-exact данные и GitHub публикация

Скопируйте папку `make-moons-mlops-labs` в существующую папку на рабочем столе. Положите отдельный `06_PUBLISH_LAB4.ps1` из ZIP в `Загрузки`.

**Ничего не удаляйте** из `data`, `reports/LAB1-LAB3`, `mlruns` и `.venv`.

Для публикации используйте `06_PUBLISH_LAB4.ps1`. Полная последовательность и остановки описаны в `GIT_AND_REPORT.md`.

Данные сохраняются байтово (CRLF); сравнение с Git выполняется по SHA-256. Все 28 файлов CSV, как и модель ЛР2, сверяются с зафиксированным манифестом исходного архива пользователя.
