# Патч №03: воспроизводимость, полное покрытие, типы и отчётность

## Установка поверх патча 02

1. Открыть `03_LAB4_Verification_and_Coverage_Patch.zip`.
2. Извлечь **содержащуюся внутри** папку `make-moons-mlops-labs` на рабочий
   стол, подтвердив слияние каталогов и замену совпадающих файлов.
3. **Не удалять** уже существующую папку проекта, `.venv`, данные ЛР1–3 или
   `mlruns/`. Они отсутствуют в патче.
4. Запустить `C:\Users\shata\Desktop\make-moons-mlops-labs\LAB4\RUN_LAB4.cmd`.
   Для повторного запуска с существующими зависимостями можно использовать
   `LAB4\RUN_LAB4.ps1 -SkipInstall` из PowerShell.
5. Убедиться, что в консоли есть `independent repeats = PASS` и `LAB4 COMPLETE`;
   все тесты `pytest` пройдены без ошибок.
6. Открыть `reports/LAB4/repeat_verification.json`: `all_pass: true`, четыре
   реальных Run ID (первый и повторный для каждого режима).
7. Посмотреть `reports/LAB4/pytest_coverage.log`, `coverage_details.json`,
   `negative_summary.json`, `source_manifest.json`, `lab4_report.md`.
8. Открыть MLflow через `LAB4/OPEN_MLFLOW_UI.cmd` → **Model training** →
   `lab4_validator`: должны быть также `lab4_full_repeat` и
   `lab4_chunks_repeat` (статус Finished).

Если при выполнении возникает ошибка, **ничего не публиковать на GitHub**,
сохранить полный вывод консоли. Обновлённый run-скрипт не меняет ЛР1–3.

## Исправлено

- Измеряется покрытие `validator.py`, `run_lab4.py`, `lab4_demo.py`, общих
  модулей `config.py`, `data.py`, `utils.py`, включая ветвления.
- Полный и потоковый режимы независимо повторяются, новые прогоны
  регистрируются в MLflow. Сохраняется `repeat_verification.json`.
- Строковые числа (`"0.5"`), логические значения (`True`, `False`), null и
  бесконечные координаты не принимаются как числовые признаки.
- Все ошибочные приёмы по flip-меткам считаются в `negative_summary.json` и
  честно описываются в отчёте. Обнаружение скрытой истинной метки без подачи
  `claimed_label` не обещается.
- `source_manifest.json` фиксирует SHA-256 байтов исходного кода, а в отчёте
  отдельно обозначено, что текущий `git HEAD` до коммита может быть старым.
- CI обновлён: тесты раннера, реальная регистрация повторных прогонов, coverage.
- Обновлены сценарий скринкаста, инструкции по рецензии и критическому отзыву.
