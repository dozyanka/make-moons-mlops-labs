# ЛР4 - валидатор входных данных

Вариант 09 - `make_moons`. Валидатор проверяет расстояние Махаланобиса, уверенность ML-модели и возможность отказа на OOD. Сравниваются режимы `full` и 24 чанка.

## Запуск на Windows

Из корня проекта запустите `RUN_DEMO.cmd` и выберите:

- **10** - полный прогон ЛР4 с pytest и MLflow.
- **11** - проверка пяти примеров входных данных.
- **12** - открыть MLflow.
- **13** - открыть авторский отчёт.

Отдельно: `LAB4/RUN_LAB4.cmd`.

Отчёт: [`reports/LAB4/lab4_report.md`](../reports/LAB4/lab4_report.md). Метрики, негативные проверки, параметры и журнал покрытия находятся в `reports/LAB4/`. Повторный запуск не формирует и не заменяет авторский Markdown-отчёт.
