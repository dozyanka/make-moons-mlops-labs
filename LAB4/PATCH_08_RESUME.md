# Патч 08 — продолжение уже начатой публикации ЛР4

Состояние после патча 07: Git уже создал ветку `lab4`, исходники и данные добавлены в индекс,
но **ни одного нового коммита ещё нет**. Git остановился на двух пробелах в `README.md`.

1. Установите этот патч (объедините папку `make-moons-mlops-labs` с папкой на рабочем столе).
2. Положите `08_RESUME_LAB4_PUBLISH.ps1` в «Загрузки».
3. Из PowerShell запустите:

   `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\08_RESUME_LAB4_PUBLISH.ps1"`

Новый скрипт **не создаёт ветку снова**, не использует `reset`, `clean`, `pull`, `force push`, не удаляет `mlruns`.
Он убирает исключительно два известных хвостовых пробела в строках описания варианта и данных
в `README.md`, обновляет индекс, проверяет хеши, создаёт коммит кода, запускает ЛР4 и
тесты, привязывает отчёт к коммиту кода отдельным коммитом и отправляет ветку `lab4`.

Требуется, чтобы текущая ветка оставалась `lab4`, её HEAD был равен локальному `main`,
а предварительно добавленные файлы оставались в индексе после остановки патча 07.
Если первая фиксация кода уже была сделана вручную, скрипт намеренно остановится.

После GitHub-публикации проверить Actions; зелёный статус не гарантируется локальным запуском.
