## ЛР2

Одна модель обучается в двух режимах:

- full dataset;
- chunks.

Pipeline:

`StandardScaler -> RBFSampler -> SGDClassifier`

Параметр `gamma` выбирается по validation-набору.

Выполнены:

- обучение full и chunks;

- сохранение моделей `.joblib`;
- MLflow;
- негативные проверки конфигурации и leakage;
- pytest и coverage.

Основные результаты находятся в:

`reports/LAB2/`

## ЛР4

Модель из ЛР2 предсказывает класс точек `make_moons`. Валидатор проверяет применимость входных данных: расстояние Махаланобиса до обучающих распределений по классам, достоверность предсказания и, если задана метка, согласованность заявленной метки с предсказанием.

- два режима вычисления статистик: **full** (16 800 строк) и **chunks** (24 чанка по 700 строк);
- сравнение статистик, метрик, памяти и времени;
- проверка сдвига средних, выбросов, чужих категорий, перевёрнутых заявленных меток;
- Precision/Recall отказа, false reject rate, ROC-AUC;
- NumPy-параметры `.npz`, SHA-256, четыре MLflow-прогона (первичные и независимые повторы);
- pytest, негативные сценарии и сохранённые результаты.

**Отчёт и результаты:** [`reports/LAB4/`](reports/LAB4/) и [указатель артефактов](reports/LAB4/README.md). **Обзор всех отчётов:** [`reports/`](reports/).

**Отдельный запуск Windows:** `LAB4/RUN_LAB4.cmd`. **Из общего меню DEMO:** пункт **10** – полный повтор с тестами, пункт **11** – пять примеров отказа/принятия, пункт **12** – MLflow ЛР4, пункт **13** – отчёт. Повтор из DEMO сохраняет новые результаты в `demo_output/LAB4` и восстанавливает исходные опубликованные файлы.

Особенность негативного контроля: изменение метки класса на противоположную нельзя определить только по признакам; при заявленной метке валидатор проверяет её согласие с моделью. Необнаруженные случаи зарегистрированы в `negative_summary.json` и отчёте.

[Инструкция по ЛР4](LAB4/README.md) · [Инструкция преподавателю](DEMO/README.md).
