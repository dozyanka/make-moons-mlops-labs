## Быстрый запуск для преподавателя

### Windows

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его.
2. Запустите двойным щелчком:

```text
RUN_DEMO.cmd
```

или:

```text
DEMO\RUN.cmd
```

Launcher самостоятельно создаёт изолированное Python-окружение `.venv`, устанавливает необходимые зависимости и позволяет запускать **ЛР1, ЛР2, ЛР3 по отдельности или все выполненные работы последовательно**.

Заранее создавать виртуальное окружение не требуется. Если подходящий Python не найден, на Windows launcher попытается установить Python 3.13 через `winget`.

### Быстрый показ готовых моделей

```text
DEMO\RUN.cmd
→ пункт 6 «Быстрая демонстрация сохранённых моделей»
```

### Полное воспроизведение ЛР1–ЛР3

```text
DEMO\RUN.cmd
→ пункт 5 «Запустить ЛР1–ЛР3 с нуля»
```

Официальные результаты остаются в `reports\LAB1`, `reports\LAB2`, `reports\LAB3`, а результаты нового запуска сохраняются отдельно в `demo_output\`, поэтому исходные отчёты не перезаписываются.

Подробная инструкция: `DEMO\README.md`.
