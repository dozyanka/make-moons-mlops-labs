## Git и pre-commit

Настроены три локальных pre-commit hook:

1. проверка синтаксиса и базового стиля Python;
2. поиск секретов;
3. блокировка файлов больше 5 MiB.

Конфигурация сохранена в reports/LAB1/precommit_config.yaml.

Финальный чистый запуск находится в reports/LAB1/precommit_clean.log.

## Негативные контроли

Реальные pre-commit hooks были проверены на трёх намеренно созданных дефектах:

1. Python-файл с синтаксической ошибкой — блокировка;
2. файл с тестовым секретом — блокировка;
3. бинарный файл размером более 5 MiB — блокировка.

Полный вывод находится в reports/LAB1/precommit_block.log.
