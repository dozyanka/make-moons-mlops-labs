# Быстрая демонстрация ЛР1-3

Из корня проекта запустите `RUN_DEMO.cmd` и выберите **6**. Это покажет предсказания сохранённых моделей ЛР1-3 и сравнит их с опубликованными метриками.

Для прямого запуска:

```powershell
.\.venv\Scripts\python.exe .\defense_demo\run_all.py
```

Результаты демонстрации сохраняются в `demo_output/defense_results/`; опубликованные файлы в `reports/` и `defense_demo/results/` не заменяются. Для ЛР4-7 используйте пункты 10-22 основного меню.
